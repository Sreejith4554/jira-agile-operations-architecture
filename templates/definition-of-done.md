# Definition of Done

A delivery item can move to **Done** only when:

- [ ] Acceptance criteria are met and evidenced.
- [ ] Required review/approval is complete.
- [ ] Related subtasks are complete.
- [ ] Known defects are resolved or formally accepted.
- [ ] Documentation is updated where required.
- [ ] Dependencies and follow-up actions are updated.
- [ ] Release / handover notes are captured if applicable.
- [ ] No unresolved blocker is hidden by closure.
