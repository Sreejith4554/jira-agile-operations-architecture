# Recommended Field Schema

| Field | Type | Purpose |
|---|---|---|
| Workstream | Select | Enables portfolio slicing |
| Business Outcome | Text | Links delivery to value |
| Dependency Owner | User | Makes external ownership visible |
| Need-by Date | Date | Dependency timing |
| RAG Status | Select | Management reporting |
| Blocker Reason | Text | Escalation context |
| Decision Required | Checkbox | Governance queue |
| Decision Due | Date | Prevents open-ended decision waits |
| Baseline Finish | Date | Variance reporting |
| Forecast Finish | Date | Current expected finish |
